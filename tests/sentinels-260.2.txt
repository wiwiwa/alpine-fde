# tests/sentinels-260.2.txt — versioned sentinel table for the ALPINE-platform
# harness (docs/Architecture.md §12 "Sentinel pinning"; gap G-E2). This is the
# DEFAULT table for the Alpine contract (tests/lib/sentinels.sh: SENTINELS_VER
# defaults to 260.2); tests/sentinels-257.13.txt remains loadable (SENTINELS_
# VER=257.13 or an explicit SENTINELS_FILE) as the Debian-era provenance
# record.
#
# Schema: identical to 257.13 — one sentinel per line, `name<TAB>string`.
# Data lines carry NO trailing comments (the awk helper greps field 2
# verbatim). All console greps in the e2e scenarios consume the selected
# table — never hardcode sentinel strings in scenario code.
#
# Name-space discipline (pinned by tests/unit/e2e_infra_smoke.sh): a name
# defined in MORE THAN ONE fixture must carry the IDENTICAL string in all of
# them — a name that changes value across eras is a silent-rot collision and
# must be RENAMED instead. The Alpine-contract strings below therefore carry
# fresh `unseal_*` / `sdboot_*` / `cli_*` names; the names shared with
# 257.13 are value-identical carries (their emitters are unchanged harness
# machinery — see the last section).
#
# ===========================================================================
# Section 1 — mkinitfs unseal hook (the pin of record: byte-extracted from
# hooks/mkinitfs/alpine-fde-unseal.sh, the shipped §8.2 hook; ADR-13/ADR-20).
# Provenance notes:
#   * unseal_pcrextend_ok: the hook printf is
#     "extended '$FDE_PCR_PHASE' into PCR 11 (ukify --measure phase
#     alignment)"; FDE_PCR_PHASE=enter-initrd is pinned at the top of the
#     hook, so the stored string is the exact runtime rendering.
#   * unseal_3strike: the hook printf interpolates $FDE_MAX_ATTEMPTS (=3,
#     pinned in the hook); the stored string is the interpolation-safe suffix
#     "… failed recovery passphrase attempts — giving up".

#     (keyslot 0): " emitted via the "alpine-fde-unseal: " prefix; stored as
#     the anchored regex shape (same discipline as 257.13's prompt_re).
#   * unseal_poweroff: the terminal fail-closed action (§8.2) — _fdh_poweroff
#     prints the reason, then "fail-closed: forcing poweroff (no shell is
#     offered, §8.2)", then `poweroff -f`. An interactive shell is NEVER
#     offered by the hook (H-G1).
